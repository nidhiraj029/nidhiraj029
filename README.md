### 📚 Wikimedia RAG Researcher

A Retrieval-Augmented Generation system designed to search and research information from Wikimedia content.

**Pipeline:**

```text
Wikimedia Dataset
       ↓
Data Ingestion
       ↓
Text Chunking
       ↓
Sentence Transformers
       ↓
FAISS Vector Index
       ↓
Semantic Retrieval
       ↓
Local LLM
       ↓
Answer Generation
```

**Current implementation includes:**

* 26,234 FAISS vectors
* `all-MiniLM-L6-v2` embeddings
* Semantic document retrieval
* Local LLM integration using Ollama
* RAG-based question answering
* Modular Python architecture

**Tech:** `Python` `RAG` `FAISS` `Sentence Transformers` `Ollama` `LLM`
